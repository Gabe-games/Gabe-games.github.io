# Motel Sleep

A first-person survival-horror game set in a strange motel in 2007.

## Current prototype

Night One: a browser-based motel-office prototype with faster first-person movement, a detailed employee break room, a rear locker hiding spot, six fixed cameras that render actual in-game locations, a multi-step shift task chain, a working vent threat, textured materials, and a bundled animated 3D creature.

The Night One loop is: answer the phone → inspect the laundry camera → check the key rack → reset the breaker → read the break-room maintenance log → return to the office and survive the vent encounter.

## Run it

This first prototype is deliberately dependency-free. Open `index.html` in a modern desktop browser while connected to the internet (Babylon.js loads from its official CDN).

Controls: **WASD** to move, **mouse** to look, **E** to interact, **1–6** to change the active security camera, and **C** to close the computer or exit the locker.
